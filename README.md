## Instruksjoner for ikonfiler (.jpg)

For at ikonene skal vises riktig i GitHub/GitLab, må bildefilene legges inn i prosjektet i henhold til instruksjonene under:

1. Opprett en mappe i rotkatalogen til prosjektet som heter `icons` (eventuelt endre stien i `src=""` dersom du bruker en annen mappe).
2. Legg `.jpg`-ikonene inn i denne mappen med følgende filnavn:
   - `javascript.jpg`
   - `nodejs.jpg`
   - `npm.jpg`
   - `python.jpg`
   - `golang.jpg`
   - `shell.jpg`
   - `terminal.jpg`
   - `arduino.jpg`
   - `raspberrypi.jpg`
3. Alle ikonene vises automatisk med en bredde på **280px** via HTML-attributten `width="280"`.

## Installasjon og kjøring

Instruksjoner for hvordan du setter opp miljøet og kjører prosjektet:

```bash
# Klone repositoriet
git clone [https://github.com/brukernavn/prosjektnavn.git](https://github.com/brukernavn/prosjektnavn.git)

# Gå inn i mappen
cd prosjektnavn

# Installere avhengigheter
npm install
